# Arrays & Matrices

Last updated: 2026-08-10

Arrays make random access cheap because neighboring values are contiguous. The
core interview skill is preserving a range or window invariant while changing
the endpoints in place.

Start with index boundaries, then layer on prefix sums, two pointers, sliding
windows, and k-sum reductions. Each is an array problem whose optimization comes
from refusing to revisit a value.
