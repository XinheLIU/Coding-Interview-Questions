# Coding Interview Questions

Last updated: 2026-08-10

A problem-first LeetCode solution library and VitePress book. Solutions are organized by problem, then connected into a learning curriculum that makes prerequisites and recurring patterns explicit.

## Characteristics

- **Problem-first organization:** every language and approach for a problem lives in one directory.
- **One source of truth:** book chapters transclude the real solution files, so code and documentation cannot drift apart.
- **Two-level curriculum:** seven learning stages contain 22 concept-sized chapters, and every problem has one leaf home.
- **Knowledge graph:** typed relationships show what each problem builds on, specializes, generalizes, or contrasts with.
- **Generated navigation:** topic indexes, difficulty indexes, sidebars, and chapter graphs are derived from problem metadata.
